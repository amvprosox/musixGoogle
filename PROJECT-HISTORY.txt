2. WHAT 1.0.8 ADDED (all platforms unless marked)
-------------------------------------------------
Offline and downloads
- Offline shuffle plays every song once; Previous goes back through what actually played.
- Downloads remember which playlist each song came from; play or shuffle only that playlist offline;
  "Download All" saves every library separately.
- Offline lyrics: saved with each download; "Get Lyrics" fills in older downloads.
- Desktop media keys and tray control the offline player.
- Playlist button says "Downloaded" (was "Already Downloaded").
- Offline mode (desktop): online-only tabs are dimmed; tapping one shows "You're offline - Open
  Downloads to play your offline music"; the offline screen has an "Open Downloads" button.

Themes and layout
- Themes: Midnight, Graphite (now the DEFAULT on every platform), Slate Grey, AMOLED Black, Light.
- Mobile layout fixes: no clipped text at large sizes, tab labels hide on narrow phones (icons stay),
  Now Playing scrolls / goes side by side in landscape, iPad caps the Downloads width.
- Desktop Downloads: album-style tiles in a responsive grid (2 columns on narrow windows), big centered
  thumbnails with title below, an "All Songs" card, playlists open in their own page with a real
  Back system (Back button, toolbar back, Esc, mouse back button).
- Desktop narrow tab bar hides labels (never icons) before they collide.
- About: "Built with love by amvprosox" plus creator info and links (Website, GitHub, YouTube,
  Instagram, LinkedIn, Email). Phone number deliberately NOT included.

Voice assistant ("Veru")
- Wake word: Veru. Accepted: veru, beru, be-ru, veyru, vey-ru, biro, bi-ro, bero, be-ro, vero, peru,
  bairu, veroo, barrow, and "hey/okay Veru". Denied: very, every, vary, berry, bury, pero, hero, zero.
  (Wake word history: prosox -> Prosecs -> Veru.)
- Fully offline engine: sherpa-onnx (keyword spotter, Silero VAD, speaker check "Only my voice").
- Editable commands, microphone picker, free-only OpenRouter AI fallback for long/odd requests.

  DESKTOP ONLY so far (Mac/Windows/Linux) - NOT yet ported to iPhone/Android:
  - Whisper speech recognition packs (base English, base multilingual, small multilingual "High accuracy").
  - 38 voice languages incl. Tagalog, Chinese, Korean, Hindi, Urdu, Russian, European languages.
  - Lauren (ElevenLabs) voice for "Yes?" and 40 spoken confirmations.
  - Multi-step commands ("play X and turn on shuffle"), follow-up questions ("which playlist?").
  - Learned phrases cache (skips the AI for repeated commands) and wake-word spelling learning.
  - Mic boost (1-12x), GTCRN noise reduction, Automatic mic avoids Bluetooth mics (keeps music quality).
  - Like Siri: music dips to 12% while you speak a command after "Veru", then comes back.
  - The mic is never played to the speakers (silent internal sink). Echo cancellation is OFF on purpose:
    on macOS it switches audio into voice-call mode (owner hated it).
  - OWNER'S MIC RULE (do not change without asking): the chosen mic is always used, EXCEPT that with
    Bluetooth earbuds (AirPods, FreeBuds, ...) Musix switches to the Mac mic while Musix is playing music,
    so music never drops to hands-free; ~2.5 s after music pauses it goes back to the earbud mic.
    Bluetooth earbuds cannot do mic + full-quality music at once (Apple/Bluetooth limit, same for Siri).
  - Microphone picker and all voice settings are always visible, even when voice is off.
  - Unverified: owner reported mic feedback with WIRED headsets too; not reproduced yet (no wired
    headset tested). Check this first in 1.0.9.
  - Waits until you finish speaking (~1.5 s of silence), ignores chatter before "Veru".
  - On-screen popup card showing the heard command, with smooth animated bars.
  - Choosing a mic (or Automatic) switches immediately.
  -> First job for 1.0.9 if wanted: port these to iOS and Android.


3. OPENROUTER (AI) NOTES
------------------------
- Key was created by OAuth (PKCE) on the owner's OpenRouter account with credit limit 0.
  It is stored ONLY as the GitHub secret OPENROUTER_KEY and injected at build time
  (XOR "musix-voice" + base64). Never in the repo. Claude never sees or types the key.
- Only ":free" models with zero price are ever called (enforced in code). Never pay a penny.
- Free plan limit: 50 AI requests per day for the whole account (needs $10 credit for 1000/day;
  owner chose not to). When the limit is hit, Musix pauses the AI until the reset and offline
  commands keep working.

6. HOW TO SET UP AGAIN (after local cleanup)
--------------------------------------------
- git clone https://github.com/amvprosox/musixGoogle.git ~/projects/musix
- Node 24 (nodejs.org tarball into ~/.local/opt/node), then: npm ci && npm run build && npm run lint && npm test
  (after npm run build: git checkout -- android/app/src/main/assets/adblock ios/Musix/Resources/Adblock)
- GitHub CLI into ~/.local/opt/gh/bin/gh, log in as amvprosox.
- Mac test build:
    cd ~/projects/musix/desktop && npm run build && \
    CSC_IDENTITY_AUTO_DISCOVERY=false npx electron-builder --config build/electron-builder.yml --mac dir --arm64
  install: replace /Applications/Musix.app with desktop/release/mac-arm64/Musix.app
- Android (only if needed): Temurin JDK 21 + Android cmdline-tools (platforms;android-35, build-tools;35.0.0),
  sherpa-onnx-2.0.1.aar into android/app/libs (CI downloads it automatically).
- iOS cannot be compiled on this Mac (no Xcode) - CI builds it.


7. HOW TO RELEASE
-----------------
- Push to main -> GitHub Actions (.github/workflows/build.yml) builds Linux, Windows, macOS, Android, iOS.
- Download artifacts: gh run download <run id> -n <artifact>
  Musix-Linux, Musix-Windows, Musix-macOS, Musix-Android-APKs, Musix-iOS-unsigned-ipa
- Rename to: Musix-X-amd64.deb, Musix-X-x86_64.AppImage, Musix-Setup-X.exe, Musix-Portable-X.exe,
  Musix-X-mac.dmg, Musix-X-mac.zip, Musix-X-android.apk, Musix-X-android-automotive.apk, Musix-X-ios.ipa
- Version bump for a new version: desktop/package.json, android/app/build.gradle.kts (versionName +
  versionCode), ios/project.yml (MARKETING_VERSION + CURRENT_PROJECT_VERSION), README download lines.
